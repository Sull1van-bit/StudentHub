Nama Aplikasi    : StudentHub
Kelompok	 : 3

Deskripsi:

StudentHub adalah aplikasi asisten untuk mahasiswa UMN berbasis Android yang dirancang khusus untuk memenuhi kebutuhan akademik dan keseharian mahasiswa.
Aplikasi ini mengatasi pencatatan perkuliahan yang selama ini terpisah antara aplikasi kalender, pencatat keuangan, dan aplikasi catatan materi perkuliahan.
